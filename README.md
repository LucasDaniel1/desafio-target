# Exercícios de Lógica de Programação

Exercícios desenvolvidos em Python para praticar lógica de programação,
manipulação de JSON, validação de dados e cálculos.

## Exercícios

### 1. Cálculo de Comissão
Calcula a comissão dos vendedores de acordo com o valor de cada venda.

- Abaixo de R$ 100: sem comissão
- De R$ 100 até R$ 499,99: 1%
- A partir de R$ 500: 5%

### 2. Movimentação de Estoque
Permite realizar entradas e saídas de produtos, validando:
- Código do produto
- Tipo de movimentação
- Quantidade
- Estoque disponível

### 3. Cálculo de Juros
Calcula os juros de uma conta de acordo com os dias de atraso.

- Multa de 2,5% ao dia
- Validação da data de vencimento
- Verificação de contas vencidas ou não
